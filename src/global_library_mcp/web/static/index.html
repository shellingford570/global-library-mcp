対応機関

国立国会図書館（NDL）、Internet Archive、Library of Congress は検索・OCR・原本画像に対応。Gallica は当ネットワークから取得できない場合があります。DDB・Europeana は書誌検索中心です。それ以外の機関は調査中であり、対応を保証しません。

利用条件

権利表示は資料ごとに各機関の表示をそのまま示します。権利が不明な資料を再配布可能とは表示しません。抜粋は短い引用と原本へのリンクを基本とし、貸出限定などアクセス制限のある資料は取得しません。

AI機能について

AI回答は実験機能です。Research Beta の初期設定では無効で、本サービスは研究資料の検索・OCR・原本確認のために提供されます。検索結果は「回答の証明」ではなく、利用者が調査するための研究資料です。

見つからなかった場合

検索予算（初期設定 Standard 25 リクエスト）の範囲で根拠が見つからなかったことは、その事実が歴史上存在しないことを意味しません。対象機関・取得範囲・図書館側の制限により結果は変わります。
