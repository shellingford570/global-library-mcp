# b11 Research Validation & Knowledge Synthesis - Overview

v1.0.0b11 builds on the released v1.0.0b10 (master `333f314`).

- Stage 0 (docs/b11-b10-regression-hardening.md,
  docs/b11-evidence-trust-model.md,
  docs/b11-research-artefact-security.md): artefact and
  evidence-reference trust boundaries rebuilt; forged
  promotions measure 0.
- Stage 1 (docs/b11-dataset-design.md,
  docs/b11-human-review.md, docs/b11-evaluation.md): a new
  294-case evaluation set with section-19 provenance, entity
  grouped splits (overlap 0), a blind human-review package;
  human evaluation remains 0 and agreement unmeasured.
- Stage 2 (docs/b11-nli-model-selection.md,
  docs/b11-nli-shadow-evaluation.md): NLI researched and
  designed only; no model downloaded; synthetic backend +
  shadow contract implemented.
- Stage 3 (docs/b11-evidence-graph.md,
  docs/b11-source-independence.md): Evidence Graph from
  trusted material only; claim structuring with extraction
  states; source-dependence rules.
- Stage 4 (docs/b11-knowledge-synthesis.md,
  docs/b11-research-report.md): template synthesis that never
  mints confirmed facts; Markdown+JSON research reports with
  full reproducibility fields and validated references.
- Stage 5 (docs/b11-workspace-integration.md): local Web API
  + UI tab inside the existing workspace security boundary;
  Zotero export gains original-title/role handling; MCP
  profiles unchanged.
- Stage 6 (docs/b11-evaluation.md,
  docs/b11-performance-evaluation.md,
  docs/b11-live-verification.md): regression, scenarios,
  metrics and CI. See docs/b12-candidates.md for the
  design-only next candidate set.
