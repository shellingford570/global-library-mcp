実API通信を伴う検証だけをここに記録する。フィクスチャ検証は
実地検証ではない。到達できなかったものは未達成と明記する。
回避（プロキシ・VPN・UA偽装・非公式ミラー）は一切行っていない。

確認日：2026-11-26（開発VM／サーバーネットワーク、特記なき場合）。

## KB / Delpher（Stage 4、アダプター経由で実地確認）

| 段階 | 結果 |
|---|---|
| SRU検索 | **確認済**：`waterkracht` で実レコード3件（例 `ddd:010286065:mpeg21:a0141`「Waterkracht-centrale.」1937-08-28） |
| 記事OCR取得 | **確認済**：同記事の resolver OCR を取得、711字、非空。OCRの単位は**記事**であり物理ページ全体ではない |
| 記事タイトル対応 | **確認済**：OCRペイロードのタイトルと、識別子完全一致で選択したSRUレコードのタイトルが一致 |
| 厳密な記事同一性・ページ同一性 | **未確認**（最終レビューで再分類）：OCRペイロード内に記事識別子が存在しないため、タイトル対応以上の同一性は証明できない。候補段階で `verified_mapping=true` としていた判定は誤りであり、最終レビューでKBの `verified_mapping` は常時 false に改めた。KBのページは検証済み根拠に入らない |
| 原本画像 | **未達成**：resolver `:image` が当該記事URNに対し404（text/plain）を返した。ページURN単位の画像経路は推測で実装せず、画像の到達性・同一性とも未確認 |
| 備考 | 初回実行でプロキシ経由の接続断（RemoteProtocolError）が発生。SRU取得に有界リトライ（1回）を追加して再実行し成功 |
