# 研究ワークスペース利用ガイド（b7）

研究ワークスペースは、発見した資料・引用・ノート・比較結果・
検索履歴をあなたのPC上に保存し、再起動後も使い続けられる
ローカル専用機能です。データが外部へ送信されることは
ありません。

## 起動方法

```bash
# Linux / macOS（確認済み手順はLinuxのみ。他OSは手順のみで未検証）
global-library-mcp web --workspace
# ブラウザで http://127.0.0.1:8000 を開く
```

- `--workspace` を付けない従来起動では、ワークスペースは
  無効で、従来どおりの検索専用モードになります。
- ワークスペース有効時はループバック（127.0.0.1）以外への
  バインドを拒否します。Dockerでは既定で無効です
  （検索専用モードは従来どおり動作します。Docker内での
  ワークスペース利用は未検証です）。
- Windows: 同じコマンドをPowerShell/ターミナルで実行して
  ください（手順のみ・未検証）。

## 保存場所

- 既定: Linux `~/.local/share/global-library-mcp/workspace.db`
  （XDG準拠）/ macOS `~/Library/Application Support/GlobalLibraryMCP/`
  / Windows `%LOCALAPPDATA%\GlobalLibraryMCP\`
- 変更: 環境変数 `GLM_WORKSPACE_PATH` または
  `--workspace-path <場所>`（.dbで終わる場合はファイル、
  それ以外はディレクトリとして扱います）。
- 起動時に保存場所が画面とコンソールに表示されます。
- リポジトリ内に研究データは作られません。DBファイルは
  暗号化されていません（権限は0600）。

## 基本操作

1. **プロジェクト作成**: ワークスペース欄で名前を入力して
   「作成」。複数プロジェクトを切り替えられます。
2. **資料保存**: 検索結果・資料結果・資料詳細のカードに
   「プロジェクトへ保存」ボタンが出ます。同じ資料の二重
   保存は拒否されます。別版・翻訳版・別コピーは別資料
   として保存できます。
3. **引用保存**: 「引用を作成」タブで機関とページIDを
   指定してページを取得し、原文の範囲を選択して保存。
   引用はサーバーが取得した原文と逐語照合されます。
   権利が不明・制限のある資料では、引用の参照情報だけが
   保存され、抜粋本文は保存されません（理由が表示され
   ます）。手入力の引用は「未確認の手入力」として区別
   されます。
4. **再検証**: 保存引用の「再検証」で現在のOCR・権利・
   ページ対応を再確認し、結果は履歴として追加されます
   （保存時の情報は上書きされません）。
5. **ノート**: あなたの考察を書く場所です。OCR原文とは
   常に区別されます。HTMLは実行されません。
6. **比較**: 保存資料タブで2〜4件にチェックを入れ、
   「文献比較」タブで実行・保存。意味比較は未検証
   （not_checked）のままです。
7. **検索履歴**: 「検索履歴を保存」にチェックした検索
   だけが記録されます。再実行は新しい履歴になります。
8. **整理**: タグ、コレクション、保存資料のローカル
   検索（外部通信なし）が使えます。

## エクスポート / インポート

- 資料: BibTeX / RIS / CSL JSON / テキスト。
- プロジェクト: Markdownレポート / JSON。
- JSONインポートは常に**新規プロジェクト**として復元
  され、IDは再割り当てされます。インポートされた検証
  状態は「過去の申告」として保持され、現在の検証済み
  にはなりません。
- 権利上出力できない抜粋は、理由とともに省略されます。

## バックアップ / 復元 / 削除

- バックアップは「エクスポート」タブから。SQLite公式
  バックアップ方式で作成され、チェックサムが記録され
  ます。DBファイルの単純コピーは（WAL運用中のため）
  バックアップとして扱わないでください。
- 復元時は現在のDBが自動でバックアップされてから
  置き換わります。破損したバックアップでは置き換わり
  ません。
- プロジェクト削除は2段階確認制で、関連件数が事前に
  表示されます。バックアップやエクスポート済みファイル
  の中にはデータが残る場合があります。

## プライバシーと権利

- 研究ノート・検索履歴が外部APIへ送信されることは
  ありません。再検証・比較のときだけ、対象資料の取得が
  上流図書館に対して行われます。
- 取得できることと、保存・再配布できることは別です。
  権利ポリシーの詳細は docs/b7-research-workspace.md と
  docs/rights-guide.md を参照してください。本システムは
  引用の法的適法性を保証するものではありません。

## 既知の制約

- 引用形式はBibTeX/RIS/CSL JSON/簡易テキストで、APA等の
  厳密なスタイル準拠は未実装です。Zotero実アプリでの
  インポート検証は未実施です（形式互換＋独立パーサーで
  検証済み）。
- タイムライン表示、関連グラフ、進捗集計（P2）は
  未実装です。
- MCPからワークスペースへはアクセスできません
  （読み取り専用プロファイル維持のため意図的です）。
